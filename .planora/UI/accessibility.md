# Aksesibilitas Antarmuka

Standar aksesibilitas untuk lingkungan kasir restoran yang sibuk dan berpencahayaan dinamis.

## Kriteria
- Target sentuh minimal 48x48px untuk seluruh tombol kasir.
- Kontras warna teks terhadap latar belakang memenuhi standar WCAG AA (rasio minimal 4.5:1).
- Dukungan navigasi keyboard numerik untuk input kuantitas dan nominal bayar.
