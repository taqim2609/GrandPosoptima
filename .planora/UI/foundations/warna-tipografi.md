# Fondasi: Warna dan Tipografi

Standar palet warna Tailwind dan sistem tipografi aplikasi kasir.

## Palet Warna
- Primary: Emerald / Hijau Tua (Melambangkan kuliner Aceh, tombol aksi kasir).
- Destructive: Rose / Merah (Tombol batal, hapus, dan void).
- Neutral: Slate / Abu-abu (Struktur card, border, dan teks pendukung).

## Tipografi
- Font keluarga: Inter / Sans-serif sistem.
- Angka uang: Monospace / Tabular figures untuk memastikan baris total dan kembalian sejajar sempurna.
