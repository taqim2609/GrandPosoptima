# Komponen: Tombol dan Input Kasir

Spesifikasi komponen input dan tombol keypad kasir.

## Spesifikasi
- Tombol Numpad: Ukuran kotak minimal 64px dengan respons sentuh instan.
- Input Nominal: Pembersihan input otomatis, pencegahan angka negatif, tombol pintasan pecahan uang (Rp 10.000, Rp 50.000, Rp 100.000, Uang Pas).
