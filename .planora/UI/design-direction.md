# Design Direction

Arah desain visual sistem kasir Grand Aceh Kuliner POS difokuskan pada kecepatan, kejelasan kontras tinggi, dan kemudahan pengoperasian di layar sentuh (touchscreen) Sunmi T2 maupun monitor desktop kasir.

## Prinsip Desain
1. **Kecepatan Operasional**: Tombol aksi utama (Bayar, Simpan, Cetak) berukuran besar dengan target sentuh minimal 48px.
2. **Kontras Tinggi**: Menggunakan palet Tailwind ramah mata kasir dengan indikator status jelas (lunas, pending, void).
3. **Tanpa Distraksi**: Tidak menggunakan ornamen dekoratif atau emoji pada elemen interaktif.
