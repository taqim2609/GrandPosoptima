# Pola Interaksi: Dialog Pembayaran

Alur penyelesaian pembayaran kasir dari pemilihan metode hingga struk tercetak.

## Alur Interaksi
1. Kasir menekan tombol "Bayar".
2. Modal menampilkan total belanja, pilihan metode bayar (Tunai, QRIS, Kartu), dan tombol pecahan uang.
3. Setelah nominal diterima, sistem menghitung uang kembalian secara otomatis.
4. Menekan enter atau tombol konfirmasi memicu pencetakan struk dan pembukaan laci kasir otomatis.
