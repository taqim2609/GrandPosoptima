# Panduan Skrip dan CLI

Skrip operasional untuk instalasi dan pemeliharaan server lokal.

## Skrip Penting
- `bootstrap-pi.sh`: Instalasi awal container Docker di Raspberry Pi.
- `backup-pi.sh`: Pencadangan database MongoDB otomatis ke arsip gzip.
- `update-pi.sh`: Penarikan pembaruan kode aplikasi dan rebuild container.
