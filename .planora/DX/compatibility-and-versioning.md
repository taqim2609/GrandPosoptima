# Kompatibilitas dan Versioning

Menjaga kompatibilitas antara web app, native bridge Android Sunmi, dan OTA bundle.

## Versi Saat Ini
- Versi APK Android: 2.10 (versionCode 21).
- Sunmi SDK: Bridge mendukung cetak thermal monospace dan perintah `openDrawer`.
- Frontend OTA: Capgo live updater menyinkronkan bundle web secara otomatis.
